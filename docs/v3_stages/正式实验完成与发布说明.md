# QoPS v3 三阶段实验：完成版本与发布说明

本说明更新早期执行计划及版本说明中的“训练中／待推送”状态。正式训练、评价和独立复算已经完成。原始数据、论文和已封存的实验交付包保持不变。

## 解决的问题与改动位置

| 问题 | 修改位置与行为 |
|---|---|
| 原 AFIL 矩阵输入不能表达同一服务多次调用的不同状态 | `prepare.py`、`modeling.py`：适配逐调用数值、类别及实体数字上下文，保留基础、直接融合、门控及身份控制对照 |
| 缺少完整三阶段输出 | `predict.py`、`evaluate.py`：分别预测网络、就绪、执行，逐调用求和得到总完成时延 |
| 选模与测试边界不清 | `orchestrate.py`、`select.py`：登记候选，仅按验证集选择，消融不参加候选选模，评价前冻结配置 |
| 无法实时观察训练或复核结果 | `monitor.py`、`plot_results.py`、`report.py`：实时训练信息、曲线、分组指标及长尾诊断 |
| 训练复现及导出精度不足 | `reproduce.py`、`verify_results.py`及预测导出代码：重放训练、独立 CPU 推理、逐条指标复算；以 float64 序列化 float32 预测，避免 CSV 缩短有效数字 |

以上相对原主分支的新增实现集中在 `experiments/v3_stages/`，说明集中在 `docs/v3_stages/`。未改写第三版原始仿真数据或旧模型入口。

## 已完成实验与验收

- 完成 152 项候选训练及 6 项消融；正式训练使用 GPU0 RTX5880，未使用 RTX6000D。
- 训练／验证／标准测试调用数分别为 144,803／48,243／48,104；学习模型使用种子 11、22、33。
- 按验证选择的完整流程：实体门控 AFIL 网络预测＋机理就绪预测＋精确执行公式。
- 标准测试网络 MAE：基础 AFIL＋身份对照为 0.259271 秒，实体门控 AFIL 为 0.053108 秒，降低约 79.52%。基础模型为新数据输入适配版，并非原论文数据集复现实验。
- 相同完整上下文 MLP 的网络 MAE 为 0.053357 秒，表明本轮主要收益来自新增数字上下文；不能把全部收益归于门控结构。
- 完整流程总时延 MAE 为 0.197772 秒、RMSE 为 4.108251 秒；仍存在少量大误差，约 0.1427% 的绝对误差超过 60 秒。
- 独立复算覆盖 441 份预测表、1,764 行指标；种子 11 重放的模型权重及验证预测逐位一致。独立 CPU 推理无需标签，结果与 GPU 推理在数值精度内一致。

执行公式、机理预测器和数据生成规则相关，当前结果属于明确假设下的仿真实验。全部候选及长尾记录保留，不据测试表现修改数据或筛选结果。
